## Contrato proposto

Esta nota planeja uma enum string; a classe PHP ainda não existe no 2.0. Cases usam TitleCase e valores persistidos estáveis. A implementação e as versões dos pacotes serão escolhidas em 2027.

| Case | Valor persistido | Significado |
| --- | --- | --- |
| `Debit` | `debit` | Débito |
| `Credit` | `credit` | Crédito |

## Regras e transições

Valor de posting sempre positivo. O lado determina o sinal. Em cada lote e moeda, soma de débitos igual à de créditos.

## Persistência

Aplicar em `ledger_postings` conforme [migrations](doc:migrations). Persistir string com cast Eloquent e restrição de valores quando apropriado. Não usar texto traduzido como valor de banco. Valores derivados ou exibidos como filtro não devem ser persistidos novamente sem necessidade.
