## Contrato proposto

Esta nota planeja uma enum string; a classe PHP ainda não existe no 2.0. Cases usam TitleCase e valores persistidos estáveis. A implementação e as versões dos pacotes serão escolhidas em 2027.

| Case | Valor persistido | Significado |
| --- | --- | --- |
| `Personal` | `personal` | Credencial do usuário |
| `Instance` | `instance` | Conexão oferecida pela instalação |

## Regras e transições

personal exige owner_user_id; instance exige autorização e limites por usuário. Não há chave compartilhada entre usuários como fallback implícito.

## Persistência

Aplicar em `ai_connections` conforme [migrations](doc:migrations). Persistir string com cast Eloquent e restrição de valores quando apropriado. Não usar texto traduzido como valor de banco. Valores derivados ou exibidos como filtro não devem ser persistidos novamente sem necessidade.
